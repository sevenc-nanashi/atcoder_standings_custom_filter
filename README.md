# AtCoder Standings Custom Filter

AtCoderの順位表でユーザーリストを用いて順位表をフィルタリングするユーザースクリプト。

## インストール

1. [ScriptCat](https://scriptcat.org/ja/)などのユーザースクリプトマネージャーをブラウザにインストールします。
2. 上記のユーザースクリプトマネージャーを使用して、以下のURLからユーザースクリプトをインストールします。

<https://raw.githubusercontent.com/sevenc-nanashi/atcoder_standings_custom_filter/built/atcoder_standings_custom_filter.user.js>
